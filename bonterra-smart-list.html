Bonterra · Marketing Operations Intern · January–June 2026

Marketo Smart List agent

Turning audience requests into Smart Lists with Claude and an existing Marketo integration.

The problem

Building a Smart List requires translating an audience request into the right Marketo filters and values. The project aimed to make that workflow easier for marketers with limited Marketo experience.

My contribution

I was responsible for creating the agent, supplying its context and rules, and getting it to work with an MCP integration that someone else had already created. My work focused on the agent and its audience-building behavior; the MCP itself was an existing team contribution.

The workflow

  1. Describe the audience. Start with a marketer’s request rather than a list of technical filter settings.
  2. Apply context and rules. Use the agent’s instructions to translate the request into audience criteria.
  3. Create through the integration. Connect the agent to Marketo using the existing MCP.
  4. Check the result. Confirm that the created Smart List accurately reflects the requested audience.

An illustrative request

“Create a reporting audience for people who attended our sample webinar, including on-demand attendees.”

Fictional example to explain the use case. It is not a customer request or a capture of the internal system.

The result

By the end of my internship, I confirmed that the agent could generate an accurate Smart List in under five minutes.

That result describes the creation I verified during the internship. It is not a guarantee for every audience request or a claim of a company-wide production rollout.

Tools and skills

Claude, Adobe Marketo Engage, an existing Marketo MCP integration, context and rule development, audience criteria, and output validation.

This case study summarizes my contribution without reproducing internal screenshots, prompts, configuration, code, or customer data. There is no public demo of the internal tool.
